# 무대 포지션 선택 UI — 설계 스펙

- 날짜: 2026-08-10
- 상태: 시안 A(정면 무대) 승인됨 · 범위 "펼친 카드만" 확정
- 시안: 세션 임시 파일 `stage-mockup.html` (repo 미포함, 가상 멤버 데이터)

## 목표

펼친 곡 카드의 세션 신청 영역(세션별 행 + "+ 하고싶어요" 버튼)을, 객석에서 바라본 무대 배치 위에서 자기 자리를 직접 골라 서는 방식으로 교체한다. 서버·API·데이터 스키마는 변경하지 않는다.

## 범위

**변경**: `public/app.js`의 `songCard()` 세션 영역 렌더, `public/style.css` 무대 스타일 추가, `public/index.html` 캐시 버스터(`?v=3`).

**유지**: 접힌 행 미니 요약(점), 곡 적기·수정 다이얼로그의 정원 스테퍼, 코멘트·플레이어·detail-top, 서버 전체, keyed diff 렌더 구조.

## UI 스펙 (시안 A)

### 무대 구조

카드 펼침 영역 안 `.stage` 박스. 상단 앰버 스포트라이트 그라데이션 + 마루판 라인, 하단에 `AUDIENCE · 객석` 점선 앞턱.

배치는 CSS grid (`grid-template-areas`):

```
키보드   드럼(단상)   ·
베이스     ·        기타
  ·      보컬        ·
```

- 드럼 존은 라이저(연한 배경 + 보더의 단상) 위에.
- 각 존: 라벨(세션색 점 + 한글명 + `cnt/cap`) 위, 스팟 줄 아래. 존 바닥에 세션색 스포트라이트 풀(radial-gradient).

### 스팟 (자리)

- 원형 버튼 46px (모바일 40px), 세션색 계열 테두리.
- **빈 자리**: 점선 테두리 + `+`. hover 시 실선·글로우·살짝 상승. 탭 = 참가.
- **채워진 자리**: 실선 테두리, 아바타(members.json 아바타 있으면 이미지, 없으면 이름 첫 글자 디스크) + 아래 이름(10.5px, 말줄임 max-width).
- **내 자리**: 앰버 테두리 + 글로우, 이름 앰버 볼드. hover/탭 시 ✕ 오버레이 = 나가기.
- **초과 자리**: 정원 넘는 인원은 빨간 테두리 스팟으로 뒤에 추가.
- 남의 자리 탭 = confirm 후 빼기 (기존 leave 규칙 그대로).

### 상태 규칙 (기존 도메인 규칙 유지)

- 정원 채움: 라벨 카운트 초록(`--ok`), 초과: 빨강(`--danger`).
- 정원 초과 신청 허용 — 서버 강제 없음, 유일한 차단은 같은 세션 같은 이름 409(서버).
- `slots[s] === 0 && members[s].length === 0`인 세션은 무대에서 숨김 (`activeSessions()` 그대로 사용).
- 전 세션 정원 0: 무대 대신 기존 문구 "세션 정원이 아직 없어요 — 수정 버튼으로 채워주세요".

### 반응형·접근성

- grid 기반이라 375px에서 자연 축소. 560px 이하: 스팟 40px, 이름 9.5px, 존 패딩 축소.
- 스팟은 전부 `<button>` + aria-label ("기타 참가", "수민 빼기"). `:focus-visible` 앰버 아웃라인. 세션 이름은 라벨 텍스트로 항상 노출(색만으로 구분하지 않음).

## 구현 설계

- `songCard()`의 `rows`(`.session-row` 목록) 생성부를 `stageHTML(song)`으로 교체. HTML 문자열 생성이므로 keyed diff·`cardCache` 구조 그대로 — 깜빡임 회귀 없음.
- 이벤트는 기존 위임 핸들러 재사용:
  - 빈 스팟: `data-act="join" data-session="…"` (기존 join 케이스 그대로)
  - 채워진 스팟: `data-act="leave" data-session="…" data-name="…"` (기존 leave 케이스가 본인/타인 confirm 분기 처리)
- `sessionStat()`·`activeSessions()`·`SESSION_META` 재사용. 세션 어휘 양쪽 중복 정의(server.js/app.js)는 변경 없음.
- 아바타: `avatarImg(name, 'spot-ava')` + 없으면 첫 글자 디스크 폴백.
- CSS는 `style.css`에 `.stage` 블록 추가, 더 이상 안 쓰는 `.session-row`·`.chips`·`.chip`·`.join` 스타일은 제거(수정 다이얼로그 등 다른 사용처 없음 확인 후).
- `index.html`의 `style.css?v=2`·`app.js?v=2` → `?v=3`.

## 엣지 케이스

- 정원 9 등 스팟 많은 세션: `flex-wrap`으로 줄바꿈.
- 긴 닉네임: 스팟 아래 이름 말줄임(64px), 전체 이름은 aria-label·title로.
- 폴링 갱신: songCard 출력이 바뀌면 카드 단위 교체 — 기존과 동일.
- YouTube 플레이어·코멘트 입력 보존 로직 영향 없음.

## 검증 (테스트 스위트 없음 — 수동)

`public/` 수정은 라이브(https://concert.okm.studio)에 즉시 반영되므로 브라우저 검증을 신속히:

1. localhost:3000 데스크톱·375px 모바일 폭에서 무대 렌더 확인.
2. 빈 자리 참가 → 스팟 채워짐·라벨 카운트 갱신, 내 자리 탭 → 나가기, 남의 자리 탭 → confirm.
3. 정원 초과 시 빨간 스팟, 정원 0 세션 숨김, 전부 0 문구.
4. 카드 접기/펼치기·폴링 중 깜빡임 없음, 플레이어 주입/제거 정상.
5. 접힌 행·곡 적기·수정 다이얼로그·플레이리스트 추출 회귀 없음.

## 성공 기준

멤버가 펼친 카드에서 무대 위 빈 자리를 탭해 참가하고, 자기 자리를 탭해 나갈 수 있다. 정원·초과·충원 상태가 무대 위에서 시각적으로 읽힌다. 기존 기능(코멘트·플레이어·필터·추출)과 렌더 성능(깜빡임 없음)에 회귀가 없다.
