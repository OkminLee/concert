# UX 개선 적용 기록

2026-09-16 · [적용 계획](2026-09-16-ux-best-practices-plan.md)

상태 필터 통합, 상세창 댓글 초안 보존, 상단 축소, 곡 검색·확인 흐름을 적용했다. 기존 Linear 테마와 보드/목록, 일정 조율, 신청·댓글·플레이리스트 API는 유지했다.

## 변경

- 상태를 하나의 선택기로 통합하고 악기·내 참여·검색 조건을 독립적으로 조합한다. 적용된 조건은 개별 해제할 수 있다. 상태별 숫자는 다른 조건을 적용한 후보 수다.
- 댓글 초안을 사용자·곡별 메모리에 유지한다. 닫기·Escape·바깥 클릭·서버 데이터 갱신에서 보존하며 저장 성공 후 해당 초안만 지운다. 전송 중 새로 입력한 내용은 지우지 않는다. 새로고침/탭 종료까지의 영구 저장은 제공하지 않는다.
- 상세창은 제목에 초기 포커스를 두고 Tab/Shift+Tab 순서를 내부에 유지한다. 내부에서 시작한 드래그로 닫히지 않으며 닫은 뒤 목록 위치와 포커스를 복원한다.
- 합주 일정 상단은 요약으로 접고 원래 정보·동작을 펼침 안에 유지한다. 모바일 도구를 두 줄로 줄이고 부가 기능을 메뉴로 모았다. 검색 도구의 상단 고정은 유지한다.
- 음악 결과를 선택하면 같은 영역에 선택곡을 표시하고 폼을 확인한다. 필드 이름은 입력 후에도 남는다. YouTube 채널명은 뮤지션으로 자동 확정하지 않는다.
- 곡 저장 실패를 폼 안에 표시하며 입력을 유지한다. 전송 중 중복 제출을 막는다. 추가 후 현재 필터를 보존하고, 새 곡이 숨겨지면 필터 해제 버튼을 제공한다.

## 검증 결과

- 기존 댓글 초안 소실을 먼저 실패하는 브라우저 검사로 재현한 뒤 수정했다.
- `npm test`: 7개 통과, 실패 0개. `node --check public/app.js` 통과.
- `ux-browser.test.cjs`: Chromium·WebKit 모두 통과. 모든 API 요청을 합성 데이터로 가로채므로 운영 API에 테스트 쓰기를 하지 않는다.
- 검사 범위: 세 가지 닫기, 내부 드래그, Tab 포커스, 갱신 중 초안, 저장 실패/재시도, 사용자별 초안, 상태 전환, 빈자리 조합, 필터 개별 해제, 검색·내보내기 범위, 세 서비스 결과 선택, 중복 제출, 추가 후 필터 유지, 검색 실패, 모바일 바깥 클릭.
- 화면 폭 320/390/768/1440px에서 문서 전체 가로 넘침 없음.
- 운영 데이터 23곡으로 390×844 화면을 측정했다. 첫 곡 시작은 약 699px에서 318px로, 온전히 보이는 행은 1개에서 6개로 바뀌었다. 일정 상태와 제목 길이에 따라 수치는 달라진다.
- 운영 검색 API를 읽기 전용으로 연결해 YouTube 12개, Apple Music 12개, Spotify 10개 결과와 선택 후 입력값을 확인했다. 검색 결과를 운영에 추가하지 않았다.
- 배포 후 index.html/app.js/discovery.css 응답이 로컬 파일 SHA-256과 일치했다. 공개 URL의 새 화면에서도 전체 브라우저 회귀 검사를 재실행했다. 별도 실제 데이터 확인에서는 데스크톱 배경 닫기와 초안 복구, 모바일 배치, 멤버 추가 반영을 확인했다.

브라우저 테스트 실행에는 Playwright 설치가 필요하다. 기본 대상은 격리 서버 `http://localhost:3917`이며 `UX_BASE_URL`로 바꿀 수 있다. WebKit 실행 파일을 별도로 지정해야 하는 환경은 `WEBKIT_EXECUTABLE`을 사용한다.

```sh
NODE_PATH=/path/to/node_modules node ux-browser.test.cjs
```

## 계획과 달라진 점

세 단계가 같은 화면 파일과 이벤트를 공유하므로 하나의 검증된 정적 파일 묶음으로 배포했다. 새로운 서버 API나 DB 변경은 없었다. 댓글 보존은 현재 페이지 수명 동안의 사용자·곡별 초안이며, 브라우저 새로고침을 넘는 저장은 이번 범위에 넣지 않았다.

자동화는 브라우저 엔진에서의 동작을 확인했다. 옥민이 사용하던 실제 데스크톱 환경의 바깥 클릭 문제 해소는 별도 사용자 확인 전까지 단정하지 않는다. 실사용 과제의 완료 시간 측정도 아직 하지 않았다.
