# MCP 곡 등록 누락 수정

- 요청: Slack 신청곡 스레드에서 봇이 곡 등록 도구 부재로 작업을 거절한 문제 수정.
- 기존 인증 아래 add_song 제공. 등록자는 기존 멤버 이름 검증 사용. 웹과 동일한 생성·링크 중복 방지·저장 경로 공유.
- 제목·뮤지션·링크·등록자·파트 정원 입력. 정원 미지정은 기존 규칙대로 0(미설정), 세션 참가를 임의 생성하지 않음.
- 격리된 임시 저장소에서 실패 테스트 → 구현 → 인증/정상 등록/중복/잘못된 입력/저장 테스트.
- 배포 후 공개 MCP 도구 목록·인증·기존 조회를 읽기 전용으로 검증한다. 사용자가 직접 재요청하기로 했으므로 실제 곡 추가는 수행하지 않는다.
- 롤백: 이번 server.js 변경을 이전 버전으로 복원하고 com.okmin.concert.server 재시작. 라이브 data.json/members.json은 덮어쓰지 않음.
