# 곡 탐색과 검색 추가

요청: 긴 곡 목록을 탐색하기 어렵다. Linear 첨부 화면처럼 상태별 그룹과 무채색 색감을 적용하고 YouTube·Apple Music·Spotify 검색에서 곡을 바로 추가하고 싶다.

현재 산출물: docs/design/linear-prototype.html. 운영과 분리된 시안이며 외부 검색은 예시 데이터다.

성공 기준: 모집 단계로 곡을 좁힐 수 있고, 곡 추가를 위해 외부 앱에서 링크를 찾아 복사할 필요가 없다. 모바일에서 가로 보드를 강제하지 않는다.

다음 작업: 시안 피드백 반영 → API 자격 증명·실제 검색 응답 확인 → 기능 구현·검증. 기존 미커밋 변경 보존.
