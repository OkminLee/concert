# 검색 결과 버전 배지

2026-09-19 사용자 요청: Jev 실사용 학습 목적으로 검색 배지를 적용. 앞선 예비 평가의 키워드 우위는 도입 차단 조건이 아니며, 정확도가 개선됐다고 주장하지 않는다.

검색 결과를 먼저 표시하고 `/api/music-labels?provider=...&q=...`로 배지를 별도 조회한다. 제목·아티스트/채널명·서비스 이름만 Jev에 보내며, 라이브와 커버는 중복 가능하다. 강좌는 별도 배지. 원곡 배지는 없다. 임계값 Choice confidence 0.7/Noul 0.9, 모델 `jev-1.13.0` 고정.

API는 기존 인증 가드 아래 설치되고 서버의 5분 검색 캐시에 있는 결과만 분류한다. 임의의 클라이언트 메타데이터를 받지 않는다. 분류 캐시는 프로세스 내 24시간/최대 약 500개(처리 중 항목 제외), 실패는 1분. 서버 재시작 시 캐시는 비워진다. 동일 요청은 중복 과금하지 않으며 동시 외부 호출 4개, 대기열 최대 48개, 호출별 4초 제한. 결과 전체를 받은 뒤 배지를 추가한다.

분류 불확실·실패 시 해당 배지를 생략하고 실패 상태는 검색 하단에 알린다. 검색/곡 선택/등록 동작을 기다리게 하지 않는다. 요청 세대가 다르면 이전 응답은 버린다. 배지에 자동 분류임을 설명하는 title을 제공한다. 키는 TYPESAFE_API_KEY 또는 ~/.concert/typesafe.json에서 서버만 읽는다.

검증: 서버 테스트(독립 라이브/커버·중복 캐시·실패·비밀값 로그 방지·동시 호출 제한·검색 캐시 없는 호출 거절), 브라우저 지연/실패/이전 응답/모바일 테스트, 기존 UX 회귀, 실제 Jev 응답 확인. 프로덕션 배포 후 정적 자산 및 인증된 API·배지 DOM을 별도 확인한다.

되돌리기: 이 기능 커밋을 revert한 뒤 com.okmin.concert.server를 재시작한다. API만 끄려면 서버 실행환경에 CONCERT_JEV_DISABLED=1을 설정하고 재시작한다. 기존 실험용 키는 별도이며 API 중단 시에도 자동 폐기하지 않는다.
