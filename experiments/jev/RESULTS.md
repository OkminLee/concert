# 합주 검색 Jev 예비 평가 — 2026-09-19

## 판단

현재 프롬프트와 표시 임계값에서는 배지 도입 보류. Jev의 추가적인 유효 배지가 없었다. 운영 검색·UI·프로세스는 변경하지 않았다.

## 방법과 한계

- 실제 YouTube 검색 5개 × 상위 고유 결과 10개 = 50건. 입력은 제목·채널명만.
- Jev 출력 확인 전에 Wednesday가 메타데이터로 참조 라벨 작성. 사람 정답·영상 청취 검증이 아닌 예비 평가다.
- 전부 음악 결과여서 강좌/기타 판별 성능은 미검증. 커버 양성은 2건으로 적다.
- 라이브·커버 독립 Noul, 콘텐츠 Choice. confidence 0.7 / noul 0.9는 임시 기준이며 교정된 정확도를 의미하지 않는다.
- 기준선은 영어·한국어·일본어의 간단한 명시 키워드 규칙. 고도화된 분류기와 비교한 결과가 아니다.

## 결과

| 지표 | 키워드 | Jev |
|---|---:|---:|
| 표시한 배지 | 11 | 10 |
| 임시 참조 라벨과 일치한 배지 | 11 | 10 |
| 참조 양성 배지 26개 중 포착 비율 | 42.3% | 38.5% |
| 배지를 붙인 검색 결과 비율 | 22% | 20% |

Jev가 붙인 배지 10개는 모두 키워드가 붙인 배지와 동일했다. 차이는 `[LIVE 한글자막] 바운디…` 1건: Jev의 live=0.84가 0.9 기준을 넘지 못했다. 임계값을 이 샘플에 맞춰 낮춰 우수하다고 보고하지 않았다.

콘텐츠 음악 분류는 Jev 44/50, 키워드 15/50이지만 ‘음악’ 자체는 배지가 아니므로 사용자 효용 개선으로 해석하지 않는다.

- 실제 API 호출 50회, 재시도 0회.
- 요청별 지연 p50 244ms, p95 405ms. 검색 화면 전체 지연이나 병렬 운영 부하 실측이 아니다.
- 입력 27,835 tokens, 출력 3,900 tokens.
- 공식 모델 가격표(https://docs.typesafe.ai/models, 확인일 2026-09-19): 입력 100만 tokens당 $0.042, 출력 무료. 이 실행의 정가 환산 약 **$0.00117**. 청구 확정액/크레딧 차감액이 아니다.

원자료: samples.json, labels.json, jev-responses.jsonl, jev-results.json. API 키는 repo 밖 ~/.concert/typesafe.json(600)에만 보관.

## 다음 검증

이 기능을 계속 검토한다면 라이브+커버·강좌·반응영상·애매한 제목을 포함한 별도 검증셋에서 프롬프트와 기준선을 비교해야 한다. 현재 샘플에 대한 임계값 조정은 탐색이며 검증 결과로 보고하지 않는다. 사람 검수 또는 영상 내용 대조 전에는 정확도 보증이나 자동 분류 배포 근거로 쓰지 않는다.

## 변경·검증·되돌리기

실험 디렉터리만 추가. 기존 운영 파일과 다른 작업의 docs/design은 수정하지 않았다. 기존 테스트 7개와 실험 테스트 3개, 총 10개 통과. 되돌리려면 이 실험 추가 커밋을 revert한다. 키 중단은 콘솔에서 concert-jev-experiment를 revoke한 다음 로컬 키 파일을 제거한다(실행한 API 호출은 취소되지 않음).
